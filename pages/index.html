US Cartograms in Vega-Lite

Contiguous, Demers, and tile-grid cartograms of the United States, from 2020 Census data — plus a ZIP-code dot map from the Vega-Lite API notebook.

  • US ZIP codes — all 42,049 ZIP codes as 2px squares under Albers USA, coloured by first digit of ZIP. From the Observable Vega-Lite API v6 notebook.
  • States cartogram test — 50 states by 2020 Census population (CA 39,538,223 to WY 576,851, 68.5×): undistorted reference map, Demers squares, and an equal-tile grid mosaic, with linked hovering.
  • States contiguous cartogram, client-side — flow-based diffusion (Gastner, Seguy & More 2018) via go-cart-wasm 0.5.0 in a Web Worker, computing live in the browser (~12 s). Mean cartographic error 0.021%, worst Alaska +0.95%, 107/107 adjacencies preserved.
  • Districts cartogram test — 435 voting congressional districts (119th Congress) by 2020 Census population: tile-grid mosaic (squared-cost lead), contiguous diffusion, Demers squares, and reference map, with linked hovering.
  • 2026 midterm results — governors, Senate, and House by party, winners shaded by margin (as of Nov 8, 2026; 23 races still uncalled).

Data: 2024 Cartographic Boundary Files (1:5,000,000) and 2020 Census P1 resident population. Source, data, layouts, and reproduction scripts: gavmor/us-cartograms.

Deployed by GitHub Actions on every push to main.
